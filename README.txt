THE LEERICK PORTFOLIO

1. Unzip this folder.
2. Copy the 14 videos from the Drive folder into the videos/ folder, renamed exactly as listed in videos/PUT-VIDEOS-HERE.txt.
3. To preview on your computer, open a terminal inside this folder and run:
     python3 -m http.server 8000
   then open http://localhost:8000 in your browser.
4. To put it online, drag the whole leerick-portfolio folder onto https://app.netlify.com/drop

Files:
  index.html        the whole site (HTML, CSS, JS and fonts in one file)
  img/avatar.png    the creative avatar
  img/wordmark.png  the TheLeerick wordmark
  videos/           the 14 project videos

To change text or project details, edit the P list near the bottom of index.html.
